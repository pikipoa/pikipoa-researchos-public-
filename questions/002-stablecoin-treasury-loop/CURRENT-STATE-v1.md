# Current State v1

Date: 2026-10-05  
Status: CURRENT

## Current conclusion

部分的にはYES。ただし、「ステーブルコイン発行体が米短期国債の重要な需要源になった」ことと、「ドル流通と米国債需要が互いを強める自己強化回路が閉じた」ことは別の主張である。

現時点では前者は強く支持される一方、後者は未確定。

## Assumptions

- **A1**: ステーブルコイン残高が増えれば、準備資産需要も増える。
- **A2**: その需要が、短期国債市場で無視できない規模になる。
- **A3**: ドルの世界流通拡大と国債需要が、互いを強める自己強化回路になっている。
- **A4**: ステーブルコインは既存金融とは異なる資金配分経路を生み、国債保有主体や信用供給を変える。

## Current assessment

- A1: 強い。ただし準備資産すべてがT-billになるわけではない。
- A2: 支持あり。ただし「構造的な限界需要」と呼べる規模の操作的定義は継続検証する。
- A3: 最も弱い。特に「国債需要・ドル体制の維持が、さらにステーブルコインによるドル流通を促す」という戻りの因果は未証明。
- A4: 傷ついている。単純な「銀行迂回」像より、銀行・非銀行発行体・国家の収斂として読む必要が強まっている。

## Important corrections already admitted

1. 2026.06原文のUSDT約1,420億ドルは誤り。米国債エクスポージャーと発行額を取り違えた。
2. 当初の賭けAは、登録時点ですでに情報価値が乏しかった。
3. 当初の賭けBは、登録前の研究ですでに観測されており、キル条件として設計不良だった。
4. Kansas City Fedの分析により、「新しい買い手の出現 = 同額の純追加需要」という単純像は維持できない。
5. 「ドル流通」と「米国債需要」を同じ政策文脈で接続する発想自体の新規性は撤回する。残る問いは、現実の因果として自己強化回路が閉じているか。
