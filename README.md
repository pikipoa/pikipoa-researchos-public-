# ResearchOS Public Records

公開記事から参照するための、検証可能なResearchOS公開記録です。

このリポジトリはResearchOS本体のcanonical storeではありません。公開対象に選んだQuestion/観測記録だけを切り出し、記事から特定commitへリンクできるようにする公開用レコードです。

## 原則

- 公開済みの原記録は上書きしない。
- 誤りは削除せず、訂正レコードを追加する。
- 記事は最新状態を読みやすく説明するProjectionであり、Git上の公開記録は変更履歴を確認するためのRecordである。
- 過去の日付をGitで遡及証明しない。Gitで第三者が追跡できるのは、この公開リポジトリのGenesis以降のみ。
- 記事v1/v2はbranch最新版ではなく、対応するcommit permalinkを参照する。
